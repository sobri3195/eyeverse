# EYEVERSE AI

**Subtitle:** Platform 41 Teknologi AI Mata + 20 Teknologi Mata  
**Branding:** Created by Dr. Sobri

## Cara Install
```bash
npm install
```

## Cara Menjalankan Dev
```bash
npm run dev
```

## Cara Build Production
```bash
npm run build
```

## Deploy ke Vercel
1. Push repo ke GitHub.
2. Import project di Vercel.
3. Framework preset: **Vite**.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

## Struktur Project
```text
src/
  assets/
  components/
  context/
  data/
  hooks/
  layouts/
  pages/
  routes/
  utils/
  App.jsx
  main.jsx
```

## Fitur Utama
- React + Vite + Tailwind + React Router DOM.
- 41 modul AI mata + 20 teknologi mata non-AI.
- Simulasi analisis dinamis berbasis input user (client-side rules engine).
- Upload image dengan validasi & preview.
- Dashboard, analytics charts, reports, history, education, chatbot, admin panel.
- Export PDF (`jsPDF`) dan CSV.
- Search, filter, sorting, pagination (load more), modal, tabs, toast, empty/loading/error states.
- Mock auth + protected routes.
- LocalStorage untuk session auth, tema, reports, history, chatbot, preferences.
